# 사이트 없이 게임 파일 만들기 (오프라인 생성기)

사이트의 **AI 문제 생성 단계만 빼고**, 나머지(게임 엔진)는 사이트와 똑같이 돌려서
`.pptx` / `.pdf` / `.html` 파일을 만듭니다. 문제는 Claude가 써 주거나 직접 씁니다.

## 가장 쉬운 사용법 (Claude에게 말하기)

> "식물의 한살이, 3~4학년, 집어!, 10문제로 만들어 줘"

Claude가 문제 파일(JSON)을 쓰고 아래 명령을 실행해 파일을 돌려줍니다.

## 직접 실행하기

```bash
cd ppt_game_maker
npm install                       # 처음 한 번만
node tools/offline/make-game.mjs tools/offline/examples/집어_식물의한살이.json --out output
```

`output/` 폴더에 `식물의 한살이_집어_게임.pptx` 가 생깁니다.
헤드리스 크롬(Playwright)이 필요합니다. Claude 클라우드 환경에는 이미 있고,
내 컴퓨터에서는 처음 한 번 `npx playwright install chromium` 을 실행하세요.

## 문제 파일 형식

```json
{
  "game": "집어!",
  "topic": "식물의 한살이",
  "grade": "초등 3-4",
  "studentCount": 24,
  "questions": [
    { "question": "씨에서 처음 나오는 잎은?", "answer": "떡잎", "wrongAnswer": "본잎" }
  ]
}
```

- `game`: 아래 표의 이름 (띄어쓰기·느낌표는 빼도 됨)
- `grade`: 뻥이요! 학습지·아이언맨 화면에 표시됨 (선택)
- `studentCount`: 탑텐짝찾기 문제 수 계산, 아이언맨 생존자 수 기본값 (선택, 기본 24)
- `wrongAnswer`: 오답. 대부분 게임에서 쓰지 않지만 넣어 두면 좋음

## 게임별 결과물과 문제 수 규칙

| 게임 | 만들어지는 파일 | 문제 수 |
|---|---|---|
| 텔레파시 | PPT | 짝수 (2문제 = 1라운드) |
| 뻥이요! | PPT + PDF (가로 A4 한 장에 같은 학습지 2부, 가운데 잘라 2명이 사용) | 자유 (반쪽 15줄 넘으면 2장) |
| 야구골든벨 OX | PPT | 자유 (정답은 반드시 O 또는 X) |
| 집어! | PPT | 자유 |
| 레벨업 골든벨 | PPT | 자유 |
| 땅따먹기 | PDF + 정답표 | 정확히 48 |
| 빙고 | 편집용 PPT + PDF + 정답표 | 16 이하 권장 (한 장) |
| 고고 전진 | 편집용 PPT + PDF + 정답표 (학습지는 가로 A4 한 장에 2부, 가운데 잘라 2명이 사용) | 12 이상 (12까지 한 장, 넘으면 2장) |
| 탑텐짝찾기 | PDF + 정답표 | 학생 수 × 2 |
| 아이언맨 | HTML | 8의 배수 (권장 40) |

규칙에 맞지 않으면 파일을 만들지 않고 이유를 알려 줍니다.

## 참고

- PDF는 압축을 켜서 한 파일에 1MB 안팎입니다.
- 야구골든벨 OX 의 X 문항은 `wrongAnswer` 에 바른 사실을 짧게 적으면 정답 화면에 "바르게 고치면: …" 으로 나옵니다.
- 엔진 코드는 `src/lib/gameEngines/` 를 그대로 씁니다. 엔진을 고치면 이 도구 결과도 같이 바뀝니다.
